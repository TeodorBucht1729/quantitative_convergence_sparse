# quantitative_convergence_sparse
Repository containing supplementary material for the paper "Quantitive Tracy-Widom laws for sparse random matrices" available at https://arxiv.org/abs/2507.19340. 

## Explanation of files

### term_tracker.py
This script is used to generate and solve the equation system presented in Section 4 of the article, and by finding a solution, this program proves that the leading terms in the expansion of d/dt E[m(t, z(t))] cancel.

### term_tracker_general.py
This script is used to generate and solve the equation system used in Section 5 of the article. By finding a solution, this program proves that the leading terms in the expansion of d/dt E[F(X(t))] cancel.

### gaussian_elim.cpp
Gaussian eliminatin with exact arithmetics using fractions. Is used to solve the system generated by term_tracker_general.py. Much faster than gaussian_elim.py, but is not called from within the script. 

### gaussian_elim.py
Gaussian eliminatin with exact arithmetics using fractions. Is used to solve the system generated by term_tracker.py. 

### identities_used_m.txt
The system and solution generated by term_tracker.py, i.e., if you are not interested in the code and only in the system we refer to in the article in Section 4, this is the interesting file for you. Further info can be found in the file.

### identities_used_F(X(t)).txt
The system and solution generated by term_tracker_general.py, i.e., if you are not interested in the code and only in the system we refer to in the article in Section 5, this is the interesting file for you. The structure is the same as identities_used_m.txt (so you have to scroll for quite a bit to get to the solution)

## Good to know
- gaussian_elim.cpp relies on the library gmp (https://gmplib.org/), so this needs to be installed to compile gaussian_elim.cpp.
